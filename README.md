# Lingua

原生 macOS 划词 / 截图翻译工具（菜单栏常驻，即用即走）。
翻译使用 Apple 端侧翻译（无需 API Key），文字识别用 Vision 在本机完成，朗读用系统原生 TTS。

> 本仓库仅包含编译好的应用（`dist/Lingua.app`），**不含源代码**，闭源分发。

## 系统要求

- **Apple Silicon Mac（M1 或更新）** —— 端侧翻译框架不支持 Intel Mac
- **macOS 15 (Sequoia) 或更新**
- 首次使用某组语言时，按系统提示下载语言包

## 下载与安装

1. 从 [Releases](../../releases) 下载 `Lingua.zip` 并解压（或直接使用本仓库 `dist/Lingua.app`）
2. 拖到 `/Applications`
3. 首次启动：应用为个人 ad-hoc 签名、未做公证，macOS 会拦截直接双击
   - **右键 `Lingua.app` → 打开 → 再点「打开」**
   - 若仍被拦截，在终端执行：`xattr -cr /Applications/Lingua.app`
4. 启动后菜单栏出现 💬 图标（LSUIElement 无 Dock 图标），点击图标或按下快捷键唤出窗口

### 需要授权的权限

| 功能 | 权限 |
|---|---|
| 划词翻译 | 辅助功能 |
| 截图翻译 / OCR | 屏幕录制 |

设置页提供跳转按钮。系统要求重启应用时，退出再打开即可。

## 快捷键（默认，可在设置中修改）

| 快捷键 | 功能 |
|---|---|
| `⌃⌥D` | 划词翻译（任意应用选中文本后按下） |
| `⌃⌥S` | 截图翻译（框选区域 → OCR → 翻译） |
| `⇧⌃⌥S` | 静默截图 OCR（仅识别并拷贝文字到剪贴板） |
| `↩︎` | 翻译（可在设置切换为 `⌘↩` 模式） |
| `⌘R` | 重新翻译 / 重试 |
| `⌘P` | 钉住窗口（置顶浮动）；未置顶时失焦自动隐藏 |
| `⌘I` | 互换语言 |
| `⌥⌘C` / `⇧⌘C` | 复制双语 / 仅复制译文 |
| `⌘S` | 收藏当前翻译 |
| `⌘+` / `⌘-` / `⌘0` | 放大 / 缩小 / 重置字体 |
| `⌘K` | 清空原文 |
| `Esc` / `⌘W` | 关闭窗口 |

## 功能说明

- **划词翻译**：选中任意应用中的文字，`⌃⌥D` 立即翻译
- **截图翻译 / OCR**：框选屏幕区域自动识别并翻译；图片 / PDF 可直接拖入输入区
  - 像素级十字准星放大镜，实时显示坐标与尺寸
  - 多显示器协同：各屏独立采集底图与裁切，跨屏平滑切换无残留
  - 悬停窗口 / 组件区域自动吸附高亮，单击截取；也可手动拖拽自定义选区
  - 截图瞬间冻结屏幕画面（视频 / 动图静止），无偏移无色差
- **查单词**：单个单词自动调取 macOS 系统词典，展示音标、词性与释义
- **收藏夹**：`⌘S` 收藏重点词汇，历史面板可筛选管理
- **语音朗读（TTS）**：点击喇叭图标朗读原文 / 译文，设备端合成
- **智能合并换行**：去除连字符与 PDF / 截图碎片化断行
- **历史记录**：本地最多 200 条，支持搜索 / 单条删除 / 一键清空
  - 文件位置：`~/Library/Application Support/Lingua/history.json`
  - ⚠️ 明文存储、不加密，关闭记录只停止新增，不会删除已有记录

## 可选：百度 / Google 翻译

默认引擎为 Apple 端侧翻译，无需配置。如需百度 / Google 作为补充结果，在设置页填入**你自己的** API Key（本应用不内置任何第三方密钥，配置仅保存在本机）。

## 更新

手动更新：下载新版 zip，退出旧 Lingua，替换 `/Applications/Lingua.app` 即可。

## 隐私

- Apple 翻译 / Vision OCR / TTS 全部在设备端运行
- 启用百度 / Google 引擎时，翻译文本会发送到对应服务
- 本应用为 ad-hoc 个人签名，未经 Apple 公证；介意签名校验的请知悉
